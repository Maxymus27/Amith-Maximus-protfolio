## Run locally

From the folder containing `index.html`:

```bash
python -m http.server 8000
```

Then open:

`http://127.0.0.1:8000/`

If `python` is not recognized on Windows, try:

```bash
py -m http.server 8000
```

Do not double-click `index.html`; use the local server so the 3D modules and assets load correctly.

## Deploy to GitHub Pages

1. Create a repository for the portfolio.
2. Upload the contents of this folder to the repository's `main` branch.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **GitHub Actions**.
5. Push to `main`. The included workflow deploys the site automatically.

The workflow is already included at `.github/workflows/deploy.yml`.
